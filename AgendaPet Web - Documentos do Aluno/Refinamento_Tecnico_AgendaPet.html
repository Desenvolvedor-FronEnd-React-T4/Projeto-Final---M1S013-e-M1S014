Por que data e hora em texto?"2026-10-20" e "09:00" ordenam e comparam corretamente como texto ("09:00" < "10:00"). Cuidado: new Date("2026-10-20") é interpretado como UTC e pode virar o dia anterior no Brasil. Para montar uma data local use new Date("2026-10-20T09:00:00") (sem o "Z").

6. Fluxos principais

6.1 Abrir a página

  1. iniciar(): aplica o tema salvo, lê o filtro, define a data mínima do formulário, liga os eventos, inicia os lembretes.
  2. carregarCatalogo(): mostra carregando → await carregarServicos() → em erro mostra a mensagem com "Tentar novamente"; em sucesso renderiza os serviços e popula o <select>.
  3. Com o catálogo pronto: restaurarAgenda() (objetos simples → instâncias via fábrica; item inválido é ignorado) e o gerador de protocolo recomeça do maior número salvo.
  4. atualizarTela(): agenda, fechamento e relógio.

6.2 Salvar um agendamento (submit)

  1. evento.preventDefault(); limpar erros antigos; ler o formulário (lerFormulario()).
  2. validarAgendamento(dados, servico) → objeto de erros por campo. Se for feriado e não confirmou, adicionar o erro.
  3. Sem erros: criar o agendamento pela fábrica e checar temConflito(estado.agenda, novo).
  4. Se há erro: mostrarErros (marca aria-invalid, escreve a mensagem, foca o primeiro inválido) e para.
  5. Sem erros: gerar o protocolo, push, salvarAgenda(), mostrar o dia do novo item, limpar o formulário, atualizarTela(), toast.

6.3 Digitar o CEP (US04)

  1. No evento input: se já tem 8 dígitos, chama consultarCep(); se tem menos, limpa a mensagem.
  2. Evita repetir a consulta do mesmo CEP (ultimoCep).
  3. await buscarCep(cep) → preenche rua, bairro, cidade e UF e leva o foco ao número. Descarte a resposta se, enquanto esperava, o CEP digitado mudou (corrida de requisições).
  4. Qualquer ErroApi vira a mensagem do item 5.4 e o preenchimento manual continua liberado.

6.4 Escolher a data (US05)

  1. Evento change da data → limpa o aviso → buscarFeriados(ano) (cache primeiro).
  2. Se a data está na lista: mostra o nome e o checkbox "Agendar mesmo assim". Se a API falhou: mostra o aviso de indisponibilidade (sem checkbox).
  3. Se a pessoa trocou a data durante a espera, descarte o resultado.

6.5 Clicar na lista (delegação de eventos)

  1. Um addEventListener('click') na <ul> (os itens são recriados a cada renderização!).
  2. evento.target.closest('[data-acao]') descobre qual botão; closest('.item').dataset.protocolo descobre qual item.
  3. Um switch trata alternar, concluir e cancelar; depois salva, redesenha e devolve o foco ao item (senão quem usa teclado se perde).
  4. Mouse: mouseover/mouseout também por delegação, com closest('.item') (eles "borbulham" dos filhos).

6.6 Relógio e lembretes (a cada 30 s)

  1. iniciarLembretes() começa com clearInterval(estado.timerLembretes) (nunca dois timers) e então setInterval(atualizarRelogio, 30_000).
  2. atualizarRelogio(): mostra a hora; proximoAtendimento(...) do dia de hoje; se faltam ≤ 15 min e os lembretes estão ativos, mostra o aviso.
  3. Só redesenhe a lista se mudou quem está atrasado (redesenhar à toa a cada 30 s tira o foco de quem navega por teclado).
  4. Pausar: clearInterval, guarda null, atualiza o botão (aria-pressed).

6.7 Fechar o dia pelo terminal

  1. node scripts/fechamento-dia.js --data=2026-10-20
  2. Lê servicos.json e agenda-exemplo.json (fs/promises) → criarAgendamento para cada item → calcularFechamento → montarLinhasRelatorio → console.log.
  3. Data inválida ou arquivo ruim: mensagem clara e process.exitCode = 1.

8.4 fetch com os 3 estados e erros por tipo (US02, US04) — js/api.js

export class ErroApi extends Error {
  constructor(tipo, mensagem) { super(mensagem); this.tipo = tipo; }   // 'rede' | 'http' | 'formato' | 'nao-encontrado'
}

async function buscarJSON(url) {
  let resposta;
  try {
    resposta = await fetch(url);                       // só REJEITA se a requisição nem chegou ao servidor
  } catch {
    throw new ErroApi('rede', 'Sem conexão.');
  }
  if (!resposta.ok) throw new ErroApi('http', `Erro HTTP ${resposta.status}`);   // 404, 500… NÃO rejeitam o fetch
  return resposta.json();                              // também é uma Promise: use await
}

10. Depuração no VS Code (US12)

  1. Abra js/dominio/fechamento.js e clique na margem esquerda da linha desejada: aparece o ponto vermelho (breakpoint).

  3. Painel Variables: valores no momento. Painel Watch: adicione expressões (ex.: concluidos.length). Call Stack: quem chamou quem.

11. CSS: Flexbox, mobile-first e especificidade

TemaOrientação
Mobile-firstEscreva primeiro o CSS do celular (uma coluna). Use @media (min-width: 640px) e (min-width: 1024px) para acrescentar ao layout maior
FlexboxColuna no celular (flex-direction: column); em ≥ 1024 px o painel vira row com duas colunas (flex: 1 1 380px e flex: 2 1 560px); flex-wrap nas linhas de campos; min-width: 0 nas colunas para o conteúdo não estourar
VariáveisCores e medidas em :root; tema escuro em :root[data-tema="escuro"] redefinindo só as variáveis
EspecificidadeClasses simples (0,1,0). Seletor de tag + classe (.agenda button = 0,1,1) vence uma classe sozinha e causa "o estilo não pega". Dê uma classe própria ao elemento. Sem !important e sem #id no CSS
hidden[hidden] perde para display: flex de uma classe (mesma especificidade, vale a ordem). Declare [hidden] { display: none; } por último no arquivo
Foco:focus-visible com contorno de 3 px e outline-offset. Nunca outline: none sem substituto
ToqueBotões e campos com min-height: 44px. O toast deve ter pointer-events: none (senão cobre botões embaixo)

14. Armadilhas frequentes (e dicas para revisar código de IA)

ArmadilhaComo evitar
fetch não rejeita em 404/500Sempre confira resposta.ok antes de .json()
ViaCEP responde 200 para CEP inexistenteConfira dados.erro
Esquecer await em resposta.json()Ele também é Promise
Abrir o HTML com duplo cliqueMódulos e fetch exigem servidor: npm start
Esquecer preventDefault() no submitA página recarrega e tudo some
novalidate ausente com validação própriaO navegador mostra os balões dele antes das suas mensagens
innerHTML com texto do usuárioUse textContent (evita injeção de HTML/script)
Listener preso a elementos que são recriadosDelegação: um listener na lista + closest()
setInterval duplicadoGuarde o id; clearInterval antes de criar outro
Instância de classe no localStorageGrave paraJSON(); restaure com a fábrica
JSON.parse(null) na 1ª visita / dado corrompidoValor padrão + try/catch
new Date("2026-10-20") vira o dia anterior (UTC)Use "2026-10-20T09:00:00" ou trabalhe com texto
Esquecer super(...) antes de usar thisEm subclasses, super() é a 1ª linha do construtor
this perdido em callbackUse arrow function ou métodos que não dependem de this externo
Limpar todo o localStorageApague só as chaves com o seu prefixo
Resposta atrasada sobrescrevendo dado novoCompare o valor atual do campo com o da consulta antes de usar a resposta
__dirname em ESM / import estático em .cjsimport.meta.url no ESM; await import() no CJS
Estilo que "não pega"Veja a especificidade no DevTools; troque seletor de tag por classe; nada de !important
Como revisar código de IA(1) Rode e quebre de propósito (rede offline, campo vazio, storage corrompido). (2) Confira se usa só o que o curso ensinou ou se você sabe explicar cada linha. (3) Procure var, innerHTML, !important, bibliotecas e alert. (4) Confirme que a regra de negócio ficou em js/dominio/. (5) Anote para a apresentação o que a IA errou e como você corrigiu.
